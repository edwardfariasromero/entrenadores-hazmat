# Entrenadores de Materiales Peligrosos

Entrenadores interactivos del Departamento de Materiales Peligrosos y Protección Ambiental (Haz-Mat Uruguay, Dirección Nacional de Bomberos), en colaboración con Produtos Perigosos del CBMAM (Brasil).

- `uruguay/` · Entrenador de Materiales Peligrosos (español), versión actual.
- `cbmam/` · Treinador de Produtos Perigosos (português), versão atual.
- `versiones/` · todas las versiones anteriores, con su número, y el historial de cambios.

Cada entrenador es un único archivo HTML que funciona sin conexión y guarda el progreso en el navegador.
